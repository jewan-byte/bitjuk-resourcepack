# bitjuk-resourcepack

dantes98 서버(빛찬이 죽이는 서버)용 리소스팩입니다.

- **비탈** (화폐) — `heartchest:banknote`
- **귀환기** (스폰으로 이동하는 귀속 아이템) — `heartchest:recall`, 커맨드 블록 모양 6배 크기
- **루비**, **정제석**, **루비 장비 6종** (철 장비 모양을 빨갛게 물들임)
- **전투 중 보스바** — 쓰이지 않는 흰색 보스바를 붉은 전투 막대로 바꿈, 교차한 검 아이콘 (폰트 heartchest:icons)
- **정제석 광석** — 자석석(lodestone) 블록을 광석 모양으로 바꿈
- **백금** (루비 상위) — 다이아 모양을 은백색으로 물들인 백금, 철 장비 모양을 은백색으로 물들인 백금 장비 6종
- **백금 광석** — 다이아몬드 블록(설치했을 때)을 심층암 백금 광석 모양으로 바꿈, 아이템은 그대로

파일
- `bitjuk-pack.zip` — 서버 `server.properties`의 `resource-pack`에 넣는 파일 (Minecraft 26.3, pack format 97.1)
- `pack-src/` — zip의 원본 파일

아이템은 서버 플러그인 HeartChest가 `minecraft:item_model` 값으로 만들어요.
